# Greek Mythology Beat 'Em Up Roguelite

Godot 4.2+ arcade-style prototype inspired by classic 2D beat-em-ups, built with original Greek mythology assets.

## Run
Open `project.godot` in Godot 4.2+ and run `Main.tscn`.

## Controls
- Move: WASD / Arrow Keys
- Attack: J / Left Mouse
- God Power: K / Right Mouse
- Select Hero / Blessing: 1, 2, 3, 4

## Included
- 4 heroes: Perseus, Athena, Hercules, Artemis
- Greek mythology enemies and Hydra boss stages
- Arcade HUD, score, combo, enemy HP, gold, blessings
- Roguelite loop: death resets the full run to Stage 1
- Stage-clear upgrades: damage, health, speed, durability, healing, level

## Note
The art direction is original arcade-inspired pixel fantasy. It does not include copyrighted Capcom assets.
